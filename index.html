Files saved here are stored online. Use Open to check a PDF/link, Download to save a code file, or Delete to remove a record. Deleting a PDF record does not delete the original file from Drive.

Connect to Firebase to load cloud files.

One-time Firebase setup

This feature uses your existing Firebase project and does not require Firebase Storage. In Realtime Database → Rules, add the following path-specific rule without replacing your other rules. It allows public reading of published learning resources but restricts changes to accounts with the trusted admin custom claim.

"developerFiles": {
  ".read": true,
  ".write": "auth != null && auth.token.admin === true"
}

Keep your existing rules for all other paths. If the database rejects saving, check these rules and confirm your signed-in developer account has the admin claim. Never put a service-account JSON/private key in this HTML.
