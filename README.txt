STUDY COMPANION WEBSITE UPDATE

Files in this package:
- index.html (updated existing website)
- privacy-policy.html
- terms-and-conditions.html
- about-us.html
- contact-us.html
- disclaimer.html
- cookie-policy.html
- copyright-policy.html
- ads.txt

DEPLOYMENT
1. Download/extract this package.
2. In your existing GitHub Pages repository, replace index.html with this updated index.html.
3. Upload all seven policy HTML files and ads.txt to the repository root (same level as index.html).
4. Commit the changes and wait for GitHub Pages to publish.
5. Test login, Google sign-in, email sign-in, profile save, AI chat, voice input, textbook links, question-paper links and PDF opening on your phone.

IMPORTANT NOTES
- Existing Firebase project configuration and authentication/database code were retained.
- The existing AdSense publisher ID and ad slot were retained from the uploaded source. Verify that this publisher ID and slot belong to your AdSense account before publishing ads.txt or enabling ads.
- AdSense approval is not guaranteed. Ensure the required consent experience and account/site eligibility are satisfied for your audience and region.
- Some Google Drive PDFs may block cross-origin fetching. In those cases the original Drive preview remains as a fallback; opening a PDF stored on the device enables the in-page PDF.js search and controls.
- Browser-level saving, screenshots or copying cannot be completely prevented.
- The request text received in chat ended partway through the technical requirements section. This package implements the complete requirements that were visible before that cutoff.
